Pubky DX Stats — Data

Daily snapshots of GitHub, npm, and crates.io activity for the Pubky org.

Endpoint

./metrics.json — full snapshot history, JSON array.

Shape

[
  {
    "date": "YYYY-MM-DD",
    "github": {
      "org_followers": number,
      "repos": { "<repo>": { "stars": n, "forks": n, "open_issues": n } }
    },
    "npm":   { "<package>": { "weekly": n } },
    "crates":{ "<crate>":   { "recent": n, "total": n } },
    "dependents": { "<crate>": { "rust": n, "npm": n } },
    "manual": { "ttfhw_minutes": n|null, "active_builders": n|null, ... }
  },
  ...
]

Cadence

Refreshed every 12 hours via GitHub Actions.
